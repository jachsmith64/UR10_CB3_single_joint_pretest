# 复用了哪些原始模块（以及为什么选这一份做基础）

## 一、找到的候选，和最后选了谁

在本机 `C:\Users\PC\Desktop\code` 下面找到的相关工程：

| 工程 | 是什么 | 结论 |
|---|---|---|
| `pre_program\UR10_vibration_pretest_v1\UR10_vibration_pretest` | 9/1 那版预实验代码：真相机采集 + RTDE + 离线角点分析，**在真机上跑通过** | ★ **选它做基础** |
| `UR10_chessboard_observability_tool`（v1.0.0～v1.3.0） | 我上一阶段写的**离线**可观测性分析工具（搜索姿态、相机位姿、测量可行性），不连设备 | 不选它当基础：它一句运动命令都不发 |
| 各种 `UR10_SFC_*` / `SFC_sim_*` / `APF_SFC_*` | SFC 控制与仿真工程 | 与本任务无关 |

**为什么选 9/1 那版**：需求一是"复用已经成功工作的相机、RTDE、界面、原始数据保存和
离线角点处理代码"，而只有这一版同时满足三条：① 相机与 RTDE 都在真机上跑过；
② 有可用的离线棋盘格处理；③ 它的参数面是"平铺的全局配置模块"，可以在**不改一行源码**
的前提下被外部改写。其余候选要么不碰设备，要么是仿真。

## 二、一行未改、直接复用的模块

都在 `src/sj_pretest/vendor/` 下，**与 9/1 原工程逐字节相同**（可用
`git hash-object` 对比，或看 git 提交 `aaa0bb9` 的说明）。复用时靠
`src/sj_pretest/bridge.py` 在**调用前**改写 `vendor/config.py` 上的属性实现参数化——
这几个模块都是 `import config` 后按属性取值，所以不需要改它们。

| 模块 | 复用什么 |
|---|---|
| `camera.py` | 海康相机打开/取流/RAW 落盘格式、缺帧记账、棋盘格检测与亚像素细化、刚性运动估计 |
| `robot.py` | RTDE 连接、Dashboard 安全检查与停止、脚本收尾、位姿读回 |
| `analyze.py` | 离线分析里可复用的统计与绘图工具 |
| `calibration.py` | 图像点 → 空间点的换算工具 |
| `config.py` | 被复用代码的参数面（路径、曝光、序列号、相机矩阵、运动开关等） |

`vendor_shim.py` 是取用它们的**唯一入口**：它校验"import 到的确实是本工具自带的这一份"，
防止别处同名模块被悄悄 import 进来。

## 三、为这个任务新写的部分

`src/sj_pretest/` 下（`vendor/` 之外的全部）：

| 模块 | 解决什么 |
|---|---|
| `joint_space.py` | 关节空间 moveJ 微动、到位中间点、组A 阶梯/组B 换向的计划与**计划自检**（不累计、只动目标关节、编号唯一） |
| `acquisition.py` | **相位感知采集**：运动前/运动/保持/回程/运动后五段在同一根时间轴上，段边界按**帧时间戳**切，不按墙钟 |
| `experiment.py` | 会话编排：连接 → 到位 → 静态 → 快速确认 → 预实验 → 正式实验；每段开始前按该段计划查磁盘 |
| `analysis.py` | 三层分析（指令→实际 / 实际→画面 / 稳定后残差）与步长推荐判据 |
| `vision.py` | J1–J5 走 88 点质心的**局部方向标量投影**；J6 走基于质心的 **2D Kabsch 旋转**；两者的静态噪声基准 |
| `recorder.py` / `replay.py` | 原始数据落盘（14 项）、历史运行读取、复算（写新目录，绝不覆盖） |
| `robot_joint.py` / `sources.py` | 三套可替换件：机器人（真机 / 合成 / 回放）、图像来源（相机 / 合成 / RAW / 图像目录） |
| `kinematics.py` | 名义运动学，只用于"理论范围检查"和姿态粗判（不是碰撞检查） |
| `ui.py` / `cli.py` | 一体化界面（三个主按钮 + 参数面板）与命令行入口 |

## 四、被复用代码里**没有**做的两件事

1. **没有碰撞模型**。原地复用它的运动接口（`moveJ` 的关节空间微动是本工具新写的部分，
   被复用代码只发过 `moveL`），但碰撞状态一律 `unknown`。
2. **没有改它的参数默认值**。9/1 那版 `config.py` 里的值原样保留在 `vendor/` 里；
   本工具的默认值写在 `src/sj_pretest/config.py`，来历都写在 `README.md` 的
   「默认值的来历」一节，其中 `robot.ip` 直接取自被复用代码的 `ROBOT_HOST`。
