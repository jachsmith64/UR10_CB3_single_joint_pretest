============================================================
 干运行示例（合成数据，全程不碰任何硬件）
============================================================

这一趟会走完整套流程：
  到位 6 个中间点 -> 静态基线 -> 快速几何确认 -> 三档预实验
  -> 离线分析 -> 推荐步长 -> 组A 正式实验

用的规模很小（只跑 J1、只跑组A 的 3 段），大概两分钟。
输出落在 outputs\dryrun_example\：

  analysis\pretest_report.txt   人看的分析报告（推荐步长和理由都在这）
  analysis\*.csv                逐条试验 / 幅度汇总 / 灵敏度 / 方向对比
  segments\*\                    每个动作一段：帧时间戳、缺帧记录、原始帧、抽帧样例图
  robot_states.csv              和采集同步记下来的关节角
  notes.txt / events.jsonl      人看的备注 + 机器读的事件流

提醒：这是**合成数据**。它只能说明流程和判据跑得通，
不是实验结果，也不能替代真实机械臂上的验证。
