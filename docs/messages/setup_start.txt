============================================================
 UR10 CB3 单关节微动预实验工具 —— 依赖安装
============================================================

这一步只做三件事：
  1) 在本目录下建一个 .venv 虚拟环境（不动系统里的 Python）
  2) 按 requirements.txt 装依赖（numpy / opencv / scipy / matplotlib / Pillow）
  3) 装完自检一次，把版本号打出来

不会做的事：
  * 不连接机械臂、不连接相机
  * 不安装 ur_rtde（那是真机上才需要的，见 START_HERE.md「上真机之前」）
  * 不安装海康 MVS SDK（那是相机厂商的安装包，不是 pip 能装的）

第一次跑要几分钟，请勿关窗口。
