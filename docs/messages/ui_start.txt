============================================================
 UR10 CB3 单关节微动预实验与正式实验一体化界面
============================================================

安全边界（请先读一遍）：
  * 默认是 dry_run（合成数据），界面上要切到 hardware 必须有人明确点头
  * 到位过程逐步人工确认，没有碰撞模型，collision_status 永远是 unknown
  * 中止之后不会自动回位，机器人停在哪里就是哪里
  * 每个动作之前都会把目标关节角打出来

操作顺序：① 连接设备并到位 -> ② 静态基线 + 预实验 -> ③ 离线分析
-> 人确认六个步长 -> 组A / 组B 正式实验

现场参数（机器人 IP、相机序列号、曝光等）在「参数面板」里改。
